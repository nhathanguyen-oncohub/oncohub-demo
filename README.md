# OncoHub – Demo logo hoa hướng dương và bảng màu website

Trang demo giúp khách hàng xem website OncoHub (Trang chủ và Trang bài viết) thay đổi như thế nào khi chọn
logo hoa hướng dương và bảng màu khác nhau.

- 12 logo hoa hướng dương và bản "Hiện tại"
- 23 bảng màu, chọn độc lập với logo
- Link chia sẻ nhớ logo, bảng màu và trang đang xem, ví dụ `#l=3&c=n5&p=art`

## Chạy cục bộ
Mở file `index.html` bằng trình duyệt (cần mạng để tải font Google Fonts).

## Deploy
GitHub Pages: Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.
Vercel / Netlify: import repo, không cần build, thư mục gốc là `.`.
